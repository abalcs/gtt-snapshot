# GTT Country Snapshot

**Live app:** https://gtt-country-snapshot.web.app

Team information resource for Audley's US Global Travel Team. It converts a 165-page Microsoft OneNote — clunky, inconsistent, and hard to search — into a modern, searchable web UI that advisors use hundreds of times daily as their go-to reference for qualifying leads.

## About this repo

The application source lives in the [`gtt-snapshot/`](gtt-snapshot/) folder (Next.js / TypeScript). See the [project README](gtt-snapshot/README.md) for local development setup.
